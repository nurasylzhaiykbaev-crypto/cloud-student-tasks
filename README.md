
# ☁️ Cloud Student Tasks

## Жобаның мақсаты
Студенттердің оқу тапсырмаларын қосуға, басқаруға және олардың орындалуын бақылауға арналған веб-қосымша жасау.

## Қолданылған технологиялар
- HTML5
- CSS3
- JavaScript
- LocalStorage
- GitHub
- GitHub Pages

## Мүмкіндіктері
- Жаңа тапсырма қосу
- Тапсырманы орындалды деп белгілеу
- Тапсырманы жою
- Барлық тапсырмалардың санын көрсету
- Орындалған тапсырмалардың санын көрсету
- Қалған тапсырмалардың санын көрсету
- Тапсырмаларды браузер жадында сақтау
- Телефонға бейімделген интерфейс

## Іске қосу
1. Репозиторийді ашыңыз.
2. index.html файлын браузерде ашыңыз.
3. Жаңа тапсырмалар қосып, функцияларды тексеріңіз.
